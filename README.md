# BookBot

BookBot is my first [Boot.dev](https://www.boot.dev) project!


A simple Python command-line tool that analyzes text files.

## Features

- Counts the total number of words
- Counts how often each letter appears
- Sorts characters from most common to least common

## Run

```bash
python3 main.py <path_to_book>
```

Example:

```bash
python3 main.py books/frankenstein.txt
```

## Output

BookBot prints:

- The book file path
- Total word count
- Character frequency report
